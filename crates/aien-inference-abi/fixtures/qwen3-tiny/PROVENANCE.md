Tiny random Qwen3ForCausalLM (seed 20261007; 2 layers, hidden 32, 4 heads, 2 KV heads, head_dim 16,
tied embeddings, q/k norm weights randomised) generated by a scratch script outside the repository
with transformers 5.17.0 + torch 2.14.0 (CPU), saved as bf16 safetensors. config.json is the
saved config rewritten in the Hugging Face 4.51 layout of the real Qwen3 checkpoints (rope_theta
and rope_scaling null instead of transformers 5's rope_parameters). forward_reference.json holds
last-position logits for ids [0, 5, 17, 42, 9, 33] computed in float32 from the bf16 weights.
The reference model is reloaded from the saved bf16 files in float32 (a bf16 round trip of the live
model also rounds the rotary inv_freq buffer and shifts logits by about 1e-4). float32 versus
float64 of the same model differ by 6.5e-7, so the oracle itself is accurate to that level.
