# User Guide

## Installation

To install the NLP library, run the following command in your terminal:

```bash
pip install nlp
```

## Configuration

You can configure the library by passing the `config` parameter to the `nlp` function. For example:

```python
from nlp import NLP

nlp = NLP(config={'model': 'en-us', 'language': 'en'})
```

## Running Tests

To run the tests, use the following command:

```bash
python -m unittest discover
```

## Getting Help

For more information, refer to the [official documentation](https://nlp-drake.github.io/docs/).
