# How to Rename a Folder of Holiday Photos Using a Bash Loop

This guide shows how to automate the renaming of a folder of holiday photos using a bash script. This is useful for organizing photos by date, making filenames more readable, or ensuring consistency across your photo library. The examples below demonstrate different renaming strategies using a simple for loop.

## Example One: Date Prefix

This example adds a date prefix to each photo filename in the format `YYYY-MM-DD-`. The script assumes the photos are in a folder named `holiday-photos`.

```bash
for file in holiday-photos/*; do
    basename=$(basename "$file")
    newname="2023-12-25-$basename"
    mv "$file" "$newname"
done
```

## Example Two: Lowercase Names

This script converts all photo filenames to lowercase to ensure consistency and avoid case-sensitive issues in file systems.

```bash
for file in holiday-photos/*; do
    basename=$(basename "$file")
    newname=$(echo "$basename" | tr '[:upper:]' '[:lower:]')

done
```

## Example Three: Number the Files

This example renames the photos sequentially with numbers, which helps in organizing files when you want to maintain a clean order.

```bash
i=1
for file in holiday-photos/*; do
    basename=$(basename "$file")
    newname="photo-$i.$basename"
    mv "$file" "$newname"
    i=$((i + 1))
done
```
