```markdown
# Documents

- [ ] Passport (with valid visa if required)
- [ ] Copy of passport and visa pages
- [ ] Travel insurance documentation
- [ ] Flight itinerary and booking confirmation
- [ ] Hotel reservation details
- [ ] Any necessary medical or vaccination records

# Clothes

- [ ] 1 set of underwear and socks
- [ ] 1 change of clothes (t-shirt, pants, or dress)
- [ ] 1 lightweight jacket or sweater
- [ ] 1 pair of shoes (comfortable walking shoes)
- [ ] Swimwear (if needed)

# Electronics

- [ ] Phone and backup power bank
- [ ] Travel charger and universal adapter
- [ ] Earbuds or headphones
- [ ] Power bank with USB-C and USB-A ports
- [ ] Camera (if needed)
```
