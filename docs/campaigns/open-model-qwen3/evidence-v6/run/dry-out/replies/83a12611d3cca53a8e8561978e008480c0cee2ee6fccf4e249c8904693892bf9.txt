# How to Rename a Folder of Holiday Photos Using a Bash Loop

This guide shows how to automate the renaming of a folder of holiday photos using a bash script. This is useful for organizing photos by date, making filenames more readable, or preparing them for upload. The examples below demonstrate different renaming strategies using loops and shell commands.

## Example One: Date Prefix

This example adds a date prefix to each photo filename in the format `YYYY-MM-DD-`. The script loops through all files and appends the current date to the original name.

```bash
for file in *.jpg; do
    date_str=$(date +%Y-%m-%d)
    new_name="${date_str}-$file"
    mv "$file" "$new_name"
done
```

## Example Two: Lowercase Names

This script converts all file names to lowercase to ensure consistency and avoid case-sensitive issues in file systems.

```bash
for file in *; do
    if [[ -f "$file" ]]; then
        new_name=$(echo "$file" | tr '[:upper:]' '[:lower:]')
        mv "$file" "$new_name"
    fi
done
```

## Example Three: Number the Files

This example renames files sequentially with numbers (e.g., photo1.jpg, photo2.jpg) to maintain a clean order.

```bash
i=1
for file in *.jpg; do
    new_name="photo${i}.jpg"
    mv "$file" "$new_name"
    i=$((i + 1))
done
```

Wrap Up:  
This bash automation saves time, ensures consistency in photo naming, improves organization, and makes it easier to search and manage holiday photos. Using loops allows for scalable renaming across large folders. The examples cover date-based, case-normalized, and sequential naming. These techniques are reliable and can be adapted for other photo collections. Always back up original files before running scripts. Proper naming helps in sorting, sharing, and long-term storage. The process is simple, repeatable, and effective for everyday use.
