# How to Rename a Folder of Holiday Photos with a Bash Loop

This guide shows how to automate the renaming of a folder of holiday photos using a bash loop. This is useful for organizing photos by date, making them easier to find, or preparing them for upload. The process involves iterating over files and applying a naming convention using shell scripting.

## Example One: Date Prefix
This example adds a date prefix to each photo filename in the format YYYY-MM-DD. The script assumes the photos are in a folder named "holiday_photos".

```bash
for file in holiday_photos/*; do
    if [[ -f "$file" ]]; then
        filename=$(basename "$file")
        date_prefix=$(date -d "2023-12-25" +%Y-%m-%d)
        new_name="${date_prefix}_${filename}"
        mv "$file" "$new_name"
    fi
done
```

## Example Two: Lowercase Names
This example converts all file names to lowercase to ensure consistency and avoid case-sensitive issues in file systems.

```bash
for file in holiday_photos/*; do
    if [[ -f "$file" ]]; then
        filename=$(basename "$file")
        new_name=$(echo "$filename" | tr '[:upper:]' '[:lower:]')
        mv "$file" "$new_name"
    fi
done
```

## Example Three: Number the Files
This example renames files sequentially with a number prefix, useful for creating a clean, ordered list of photos.

```bash
i=1
for file in holiday_photos/*; do
    if [[ -f "$file" ]]; then
        filename=$(basename "$file")
        new_name="photo_${i}_${filename}"
        mv "$file" "$new_name"
        i=$((i + 1))
    fi
done
```

Wrap Up: This bash script efficiently organizes holiday photos using simple loops and file operations. It improves searchability, maintains consistency, and reduces manual effort. You can adapt the naming rules to fit your needs. Always backup your files before running such scripts. The examples cover date-based, case-normalized, and numbered renaming. These techniques are reliable and widely applicable in photo management workflows.
