# Welcome

Welcome to the team! We're excited to have you join us and contribute to our mission of building innovative solutions. Your onboarding process is designed to help you get up to speed quickly and feel supported throughout your first weeks.

# Accounts and access

You will receive a dedicated email address and a team-specific GitHub account to access code repositories. All access is granted through the company’s identity management system, which requires two-factor authentication for security. Once your access is approved, you’ll receive an email with login instructions and a list of your assigned permissions.

# Tools to install

You should install the latest version of Git, Python 3.10, and Docker to ensure compatibility with our development environment. Additionally, configure your terminal with the team’s preferred shell settings and install the VS Code extension pack for Python and Git integration. These tools are essential for running local development and testing workflows.

# Your first week

During your first week, your primary focus will be on familiarizing yourself with the codebase and team workflows. You will attend a mandatory onboarding session with the engineering lead and participate in a pair programming exercise to understand the project structure. You will also be assigned a mentor who will guide you through key tasks and answer questions.

# Who to ask

If you have questions about the code, workflows, or team processes, reach out to your assigned mentor or the engineering lead. For design or product-related queries, contact the product manager or UX lead directly. Communication is encouraged at all levels—don’t hesitate to ask for clarification.

# Glossary

Git is a distributed version control system used to track changes in source code. Docker is a platform that allows developers to package applications and their dependencies into containers for consistent environments. A pull request is a proposal to merge code changes into a shared repository, reviewed by team members before approval. A sprint is a time-boxed period during which specific work is completed. Onboarding refers to the process of integrating a new team member into the team’s culture, tools, and workflows. A CI/CD pipeline automates testing and deployment processes to ensure code quality and reliability.
