## Building

The build process compiles the source code into executable binaries using a standard build toolchain.  
```bash
make build
```
This command runs the `build` target in the Makefile, compiling all C and C++ source files into object files and linking them into the final executable.

## Testing

The testing phase runs unit and integration tests to ensure code correctness and stability.  
```bash
make test
```
This command executes all test cases defined in the `test/` directory using the built-in test runner, reporting failures and coverage statistics.

## Packaging

The packaging step creates a distributable archive of the application for deployment.  
```bash
make package
```
This command generates a compressed tarball with the binary, configuration files, and documentation, ready for distribution to production environments.

## Summary
The pipeline ensures that code is built, tested, and packaged consistently and reliably. Each stage is automated and verified to maintain code quality and reduce human error.
