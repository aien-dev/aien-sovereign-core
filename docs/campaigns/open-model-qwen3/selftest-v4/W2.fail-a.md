# Nightly backups

This page describes the nightly backup routine for the small file server.
It runs from cron at two in the morning.
The archive is kept for fourteen days.
A failed run sends a message to the on-call phone.
The routine has three steps and a restore guide.
No step needs a person to be present.

## Create the archive

```sh
tar -czf /backup/files-$(date +%F).tar.gz /srv/files
```

## Copy it offsite

```sh
rsync -a /backup/ backup@remote:/vault/files/
```

## Verify the copy

```sh
sha256sum /backup/*.tar.gz
```

## Restore notes

Copy the archive back.
