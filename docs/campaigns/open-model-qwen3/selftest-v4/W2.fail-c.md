# Nightly backups

This page describes the nightly backup routine for the small file server.
It runs from cron at two in the morning.
The archive is kept for fourteen days.
A failed run sends a message to the on-call phone.
The routine has three steps and a restore guide.
No step needs a person to be present.
It runs from cron at two in the morning.

## Create the archive

The first step packs the shared folder into one dated archive.

```sh
tar -czf /backup/files-$(date +%F).tar.gz /srv/files
```

## Copy it offsite

The second step sends the archive to the remote machine.

```sh
rsync -a /backup/ backup@remote:/vault/files/
```

## Verify the copy

The third step compares checksums on both sides by running sha256sum.

## Restore notes

To restore, copy the newest archive back to the server and unpack it in the root folder. Check the checksum first, and keep the previous archive until you have confirmed that the files open correctly.
