# Rename Photos with a Bash Loop

Renaming a folder of holiday photos using a bash loop can be a quick and efficient way to organize your images. This guide will walk you through the process using different naming strategies.

## Example One: Date Prefix

This example uses the date as a prefix for each photo. It ensures that the filenames are unique and include the date of the photo.

```bash
for file in *.jpg; do
  newname=$(date -r "$file" "+%Y-%m-%d")_$(basename "$file")
  mv "$file" "$newname"
done
```

## Example Two: Lowercase Names

This example converts all filenames to lowercase, which is useful for consistency and compatibility with certain systems.

```bash
for file in *.jpg; do
  newname=$(echo "$file" | tr '[:upper:]' '[:lower:]')
  mv "$file" "$newname"
done
```

## Example Three: Number the Files

This example numbers the files sequentially, which is helpful for organizing photos in a specific order.

```bash
counter=1
for file in *.jpg; do
  newname="photo_$counter.jpg"
  mv "$file" "$newname"
  counter=$((counter + 1))
done
```

## Wrap Up

Renaming photos with bash loops can save time and help maintain an organized file structure. Each method serves a different purpose, so choose the one that best fits your needs. Always make sure to back up your files before making bulk changes. This guide provides a solid foundation for managing your holiday photos efficiently.
