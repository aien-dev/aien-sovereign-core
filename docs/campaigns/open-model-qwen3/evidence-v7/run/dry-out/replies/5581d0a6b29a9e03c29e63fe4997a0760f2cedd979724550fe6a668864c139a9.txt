# Rename Holiday Photos with a Bash Loop

Renaming a folder of holiday photos using a bash loop can help organize your images by date, format, or other criteria. This guide provides a step-by-step approach to achieve this using command-line tools.

## Example One: Date Prefix

To rename photos with a date prefix, you can use a bash loop that appends the date to each filename. This is useful for organizing photos by the date they were taken.

```bash
for file in *.jpg; do
  newname=$(date -r "$file" "+%Y-%m-%d")_$(basename "$file")
  mv "$file" "$newname"
done
```

## Example Two: Lowercase Names

If you want to ensure all filenames are in lowercase, you can modify the loop to convert filenames to lowercase. This helps maintain consistency across different operating systems.

```bash
for file in *.jpg; do
  newname=$(echo "$file" | tr '[:upper:]' '[:lower:]')
  mv "$file" "$newname"
done
```

## Example Three: Number the Files

To number the files sequentially, you can use a counter variable within the loop. This is helpful for creating a consistent naming pattern for all images.

```bash
count=1
for file in *.jpg; do
  newname="photo_$count.jpg"
  mv "$file" "$newname"
  count=$((count + 1))
done
```

Wrap Up
Renaming photos with bash loops is a powerful way to organize your files. It allows for automation, consistency, and easy management of large collections. Always ensure you have backups before running renaming scripts.
